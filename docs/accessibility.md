# Accessibility notes

Last walk-through: v0.0.6 (2026-10-09).

- Automated scan (axe-core) of every page in light and dark mode: no issues (v0.0.5).
- Keyboard: from the dashboard, Tab goes Skip to content, organization switcher, then each sidebar link in order, then Terms, Privacy. Every control has a visible focus outline.
- Forms: every field has a label; the two-step code field uses the one-time-code hint so phones can fill it.
- Still to do by a person: a full screen reader pass (VoiceOver or NVDA) of sign-in, new transaction, import and statement check.
